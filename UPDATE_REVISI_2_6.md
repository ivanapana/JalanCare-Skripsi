# Patch 2.6 berdasarkan kode Ivana

1. Hentikan server lama dengan Ctrl+C. Simpan cadangan folder proyek.
2. Ekstrak ZIP, buka salin_ke_folder_proyek.
3. Salin isi folder tersebut ke C:\Skripsi 1\Train\website_lubang_jalan_revisi_2_2; Replace hanya file dalam patch. models/privacy dari paket harus disalin juga bila belum ada. best_potholes.pt, .venv, .env, private dan secrets tetap dipertahankan.
4. Jalankan run.bat, lalu Ctrl+F5. Footer Revisi2.6. Dependensi tidak berubah; tidak perlu setup/training ulang. Akun demo/password sama dengan2.5.1, tidak direset pada setiap update.

Password minimal8 dan alasan penolakan kini memakai notifikasi website di bawah kolom serta ringkasan error, bukan balon validasi browser. Validasi server tetap bekerja ketika JavaScript tidak berjalan.

Kategori petugas: Baik/Sedang/Rusak/Rusak Berat. Jika surveyor mengisi nilai SDI, kategori harus cocok dengan batas pada naskah: <=50 Baik; >50–100 Sedang; >100–150 Rusak; >150 Rusak Berat. Nilai SDI diisi surveyor, tidak dihitung dari foto. Kategori lama tidak dikonversi otomatis.

Rekap/status/baris laporan baru diperbarui otomatis sesuai filter. Detail mempunyai peta inline dan data pemeriksaan terbaru. Provider peta dapat gagal; tautan lokasi tetap tersedia.

Narasi memakai draf terstruktur sementara, belum formulir resmi dinas. Baca FORMAT_LAPORAN_DINAS.md dan kirim contoh formulir kosong/tersamarkan untuk penyesuaian format berikutnya. Tidak mengklaim laporan telah disetujui Dinas.

Mode Firebase: untuk mengirim laporan, Storage bucket dan Gemini harus aktif. Jika Gemini gagal atau Storage belum dikonfigurasi, laporan tidak disimpan; tidak dialihkan diam-diam menjadi laporan template/foto lokal. Login/konfigurasi akun Firebase masih dapat dilakukan lebih dahulu. Mode demo tetap dapat memakai template berlabel.

AUDIT_CAKUPAN_2_6.md mencantumkan pemetaan lengkap, pengujian, dan hal yang masih memerlukan konfigurasi/eksperimen/UAT. Seluruh cakupan belum boleh disebut lulus hanya berdasarkan kode ini. Skripsi PDF tidak diubah.
